# 🐾 Pets Finder App

A Flutter application that allows users to **view, search, and favorite pets**.  
Users can easily browse pets, filter by breed, and manage their favorite list — all in a clean and responsive UI.

---

## 🚀 Features
- 🐶 View all available pets  
- 🔍 Search and filter by breed  
- ❤️ Add and remove pets from favorites  
- 🧪 Comprehensive unit and widget testing  
- 🌐 Clean architecture with BLoC and Dependency Injection  


## 🛠️ Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/ShazaMashaal/pets_finder_app.git
   cd pets_finder_app

2. Install dependencies

flutter pub get


3. Run the app

flutter run


4. Run tests

flutter test
